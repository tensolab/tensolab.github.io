TypeScript

简介

简介

TypeScript由微软开发，是基于JavaScript的一个拓展语言。

TypeScript包含了JavaScript的所有内容。即TypeScript是JavaScript的一个超集。

TypeScript增加了静态类型检查、接口、泛型等很多现在开发特性，因此更适合大型项目开发。

TypeScript需要编译为JavaScript，然后交给浏览器或其他JavaScript运行环境执行。

TypeScript
JavaScript

背景

今非昔比的JS

JavaScript当年诞生时的定位是浏览器脚本语言，用于在网页中嵌入一些简单的逻辑，而且代码量很少。随着时间的推移，JavaScript变得越来越流行，如今的 JavaScript已经可以全栈编程。现如今的JavaScript应用场景比当年丰富的多，代码量也比当年大很多，随便一个JavaScript项目的代码量，可以轻松的达到几万行，甚至十几万行！然而JavaScript当年"出生简陋"，没考虑到如今的应用场景和代码量，逐渐的就出现了很多困扰。比如数据类型不清不楚、有逻辑漏洞、能访问不存在的属性、低级的拼写错误等。为了解决这些问题TypeScript应运而生。TypeScript是一个静态类型检查即在代码运行前进行检查，发现代码的错误或不合理之处。

注意

在JavaScript中一些内置构造函数比如Number、String、Boolean它们用于创建对应的包装对象，在日常开发中很少使用。在TypeScript中也是同理，所以在TypeScript中进行类型声明时，通常使用小写的number、string、boolean

// TS官方推荐写法
// string表示只能赋值为字符串原始类型，不能赋值为String包装对象
let str1: string
str1 = 'hello' // 正确
str1 = new String('hello') // 报错：不能将类型"String"分配给类型"string"

// String表示既能赋值为字符串原始类型，又能赋值为String包装对象
let str2: String
str2 = 'hello' // 正确
str2 = new String('hello') // 正确

JavaScript 基本类型 vs 包装类型

对比项基本类型包装类型
包含种类string、number、boolean、null、undefined、bigint、symbolString、Number、Boolean
存储位置栈内存，直接存值堆内存，对象，存储引用地址
可变性值不可变，操作只会返回新值对象，可以添加、修改属性
typeof 结果对应类型，例：typeof 'abc' → stringtypeof new String('abc') → object
instanceof原始值使用 instanceof 全部返回 falsenew String() instanceof String → true
访问属性方法本身没有方法；JS会临时包装，调用后销毁本身就是对象，可直接访问属性方法
创建方式字面量：let str = 'hi'new String('hi') / new Number(123) / new Boolean(true)
比较规则做值比较做引用比较，相同值的不同实例也不相等
使用场景业务开发99%都使用原始类型极少手动new，大多是引擎内部临时创建

new String / new Number / new Boolean基本不用哟

常用类型

any

any的含义是任意类型，一旦将变量类型限制为any，就意味着放弃了对该变量的类型检查

// 显式any
let a: any
a = 'hello' // 正确
a = 28 // 正确
a = true // 正确

// 隐式any
let b
b = 'hello' // 正确
b = 28 // 正确
b = true // 正确

// any类型的变量可以赋值给其它任意类型的变量
let x: string
x = a // 正确, 但是这样会破坏x的类型

unknown

unknown的含义是未知类型，可以理解为一个类型安全的any，适用于不确定数据的具体类型

let a: unknown
a = 'hello' // 正确
a = 28 // 正确
a = true // 正确

// unknown类型的变量不可以赋值给其它类型的变量除非进行类型断言
let x: string
x = a // 错误: 不能将类型“unknown”分配给类型“string”。

// 通过类型保护来缩小类型
if (typeof a === 'string') {
  x = a // 正确: 在类型保护下，a被缩小为string类型
}

// 通过类型断言来告诉编译器a的实际类型
x = a as string // 正确: 使用类型断言将unknown类型的a转换为string类型

// 通过尖括号语法进行类型断言
x = <string>a // 正确: 使用类型断言将unknown类型的a转换为string类型

读取any类型数据的任何属性都不会报错，而unknown正好与之相反

let str1: string
str1 = "Hello, World!"
str1.toUpperCase() // 正确

let str2: any
str2 = "Hello, TypeScript!"
str2.toUpperCase() // 正确

let str3: unknown
str3 = "Hello, Unknown!"
str3.toUpperCase() // 报错："str3"的类型为"未知"

never

never的含义是：任何值都不是，简言之就是不能有值，undefined、null、''、0都不行

几乎不用never去直接限制变量，因为没有意义

// 指定a为never类型，意味着a不能被赋值为任何类型的值
let a: never
a = 1 // 报错：不能将类型“1”分配给类型“never”
a = "string" // 报错：不能将类型“string”分配给类型“never”
a = undefined // 报错：不能将类型“undefined”分配给类型“never”
a = null // 报错：不能将类型“null”分配给类型“never”

never可用于限制函数的返回值

/**
 * 限制函数不需要有任何返回值，函数默认返回的undefined都不行
 * 此时要么函数抛出异常，要么函数死循环
 */
function throwError(str: string): never {
  throw new Error(str);
}

never一般是TypeScript主动推断出来的

let a: string
a = "Hello, World!"

if (typeof a === "string") {
    console.log(a.toUpperCase())
} else {
  // TypeScript会推断出a是never，因为没有任何一个值符合此处的逻辑
  console.log(a)
}

void

void通常用于函数返回值声明，含义为函数不返回任何值，调用者也不应依赖其返回值进行任何操作

/**
 * 没有编写return去指定函数的返回值，所以函数是没有显式返回值的
 * 但是会有一个隐式的返回值，就是undefined
 * 虽然函数返回类型为void，但实际上函数仍然会返回undefined
 * 所以undefined是void可以接受的一种空
 */
function logMessage(message: string): void {
  console.log(message)
}
let result = logMessage("Hello, TypeScript!")
if (result) { // 报错：无法测试"void"类型的表达式的真实值

}

function logMessage1(message: string): undefined {
  console.log(message)
}

let result1 = logMessage1("Hello, TypeScript!")
if (result1) { // 正确
  
}

object

object的含义是：所有非原始类型，对象、函数、数组等。由于限制的范围比较宽泛，在实际开发中使用的相对较少。

class Person { }

// a能存储的类型是非基本类型
let a: object
a = {}
a = { name: '张三' }
a = [1, 2, 3]
a = function () { }
a = new String('abc')
a = new Person()
a = 1 // 报错
a = true // 报错
a = 'abc' // 报错

// b能存储的类型是可以调用到Object方法的类型 
let b: Object
b = {}
b = { name: '张三' }
b = [1, 2, 3]
b = function () { }
b = new String('abc')
b = new Person()
b = 1
b = true
b = 'abc'
b = null // 报错
b = undefined // 报错

声明对象类型

固定属性
let person: {
  name: string,
  age: number
}

// 正确
person = {
  name: '张三',
  age: 18
}

// 报错：缺少age属性
person = {
  name: '李四',
}
可选属性
// 在属性上使用问号表示该属性是可选的
let person1: {
  name: string,
  age?: number
}

// 正确
person1 = {
  name: '李四',
}
增加属性
/**
 * 限制person对象必须有name和age属性
 * 同时可以有任意数量、任意类型的其它属性
 */
let person: {
  name: string
  age: number
  [key: string]: any
}

person = {
  name: '张三',
  age: 18,
  gender: '男',
  hobby: ['篮球', '足球'],
}

声明函数类型

/**
 * 声明一个函数类型
 * => 左边是参数类型，右边是返回值类型
 */
let count: (a: number, b: number) => number

// 完整写法
count = function (a: number, b: number): number {
    return a + b
}

// 简洁写法
count = function (a, b) {
    return a + b
}

// 箭头函数写法
count = (a, b) => a + b

声明数组类型

// 写法1
let arr1: string[]
// 写法2
let arr2: Array<number>

arr1 = ['1', '2', '3']
arr2 = [4, 5, 6]

tuple

元组(tuple)是一种特殊的数组类型，可以存储固定数量的元素，并且每个元素的类型是已知的且可以不同。元组用于精确描述一组值的类型，?表示可选元素。

/**
 * 只能有两个元素
 * 第一个元素必须是string类型，第二个元素必须是number类型
 */
let arr1: [string, number]
arr1 = ['hello', 42]

/**
 * 只能有两个元素
 * 第一个元素必须是string类型，第二个元素可以是boolean类型，也可以没有
 */
let arr2: [string, boolean?]
arr2 = ['hello', true]

/**
 * 可以有两个或更多元素
 * 第一个元素必须是number类型，后续的元素必须是string类型
 */
let arr3: [number, ...string[]]
arr3 = [1, 'hello', 'world']

enum

枚举(enum)可以定义一组命名常量，它能增强代码的可读性，也让代码更好维护

enum Direction {
  Up,
  Down,
  Left,
  Right
}

console.log(Direction.Up); // 0
console.log(Direction.Down); // 1
console.log(Direction.Left); // 2
console.log(Direction.Right); // 3

console.log(Direction[0]); // Up
console.log(Direction[1]); // Down
console.log(Direction[2]); // Left
console.log(Direction[3]); // Right

// 枚举应用
function walk(direction: Direction) {
  if (direction === Direction.Up) {
    console.log("Walking up");
  } else if (direction === Direction.Down) {
    console.log("Walking down");
  } else if (direction === Direction.Left) {
    console.log("Walking left");
  } else if (direction === Direction.Right) {
    console.log("Walking right");
  } else {
    console.log("Unknown direction");
  }
}

walk(Direction.Up); // Walking up

type

type可以为任意类型创建别名，让代码简洁，可读性更强，同时能更方便地进行类型复用和扩展。

单一类型
// 创建一个shuzi类型其和number类型等效
type shuzi = number
let a: shuzi
a = 5
联合类型

type Status = number | string

// 使用type定义函数只能返回void类型
type fn = () => void

/**
 * 虽然使用type定义了fn返回的是void类型即只能返回undefined
 * 但是这里可以返回任意类型
 * 这样做是为了让箭头函数简写形式成立、
 * 具体请看下方代码
 */
let a: fn = function () {
  return 66
}

let arr = [1, 2, 3]
let arr1 = [0]
/**
 * forEach里面的函数要求返回类型为void
 * 这样写没有任何问题，会隐式返回undefined
 */
arr.forEach((item) => {
  arr1.push(item)
})

/**
 * forEach里面的函数要求返回类型为void
 * 这样简写会返回arr1.push(item)调用之后的值即数组长度
 * 而函数要求返回void这里返回了number类型造成冲突
 * 因此为了让这种简写形式能够成立
 * TS规定使用type定义返回类型为void的函数可以返回任意类型
 */
arr.forEach(item => arr1.push(item))

    super(name, age)
    this.gender = gender
  }

    console.log(`${this.gender}${this.name}正在努力学习中...`)
  }

stu1.speak()
stu1.study()

    protected name: string,
    protected age: number
  ) { }

    return `我叫${this.name}, 今年${this.age}岁`

抽象类

抽象类是一种无法被实例化的类，专门用来定义类的属性和行为，类中可以写抽象方法，也可以写具体实现。抽象类主要用来为其派生类提供一个基础结构，要求其派生类必须实现其中的抽象方法。

// 定义Package抽象类
abstract class Package {
  // 构造器
  constructor(public weight: number) { }

  // 抽象方法
  abstract calculate(): number

  // 具体方法
  printPackage() {
    console.log(`包裹重量为${this.weight}Kg, 运费为${this.calculate()}元`)
  }
}

// StandardPackage类继承Package
class StandardPackage extends Package {
  constructor(
    weight: number,
    public unitPrice: number
  ) {
    super(weight)
  }

  // 实现抽象方法
  calculate(): number {
    return this.weight * this.unitPrice
  }
}

const s1 = new StandardPackage(10, 5)
s1.printPackage()
