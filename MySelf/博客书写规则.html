春眠不觉晓，处处闻啼鸟。

[唐朝]孟浩然(689年—740年)早年隐居在鹿门山，后入长安谋求官职，考进士不中，还归故乡。《春晓》即是他隐居鹿门山时所作。

春日熟睡不知不觉天已破晓，到处都可以听见鸟儿的啼叫。

回想昨夜听到的阵阵风雨声，不知有多少艳丽春花被吹落。

容器首行 meta，竖线分隔：::: poem 春晓|唐|孟浩然；朝代缺失时写 ::: poem 杂诗·其一||佚名，作者也缺就只写诗题；朝代显示在作者行前面，并在右上角盖一枚朱印——印面照朝代原样刻字，写几个字就印几个字，印形随字数变：1 字方印、2–3 字竖排长方印、4 字田字印、5 字以上竖长条。

@原文段落optional

诗歌本体，一行一句，逐句居中、衬线大字

@赏析段落optional

@译文段落optional

一行一句，左对齐两端对齐，比原文小一档字号

@注释段落optional

一行一句，渲染在最后、字最小，适合人名、典故这类查考内容

提示符支持逐行改：命令上方写 @ 提示符 只改这一行，写 @+ 提示符 则从这一行往下一直生效直到下一个 @/@+ 或容器结束。优先级 @ > @+ > 头部 prompt > 类型默认值。下面模拟切换用户和目录时提示符的变化：

Terminal

普通用户，沿用默认提示符 $

$whoami

sudo root@server:~#sudo -i

root@server:/var/log#cd /var/log

root@server:/var/log#tail -f syslog

root@server:/var/log#grep -i error syslog

::: term sh
// 普通用户，沿用默认提示符 $
whoami
@ sudo root@server:~#
sudo -i
@+ root@server:/var/log#
cd /var/log
tail -f syslog
grep -i error syslog
:::

还能还原一段完整的终端会话：| 开头是命令输出(顶格、无提示符)，@! 开头是只有提示符的"等待输入"行。这两类都不参与打字动画、也不会被复制按钮复制：

命令提示符

C:\Users\tensoflow>cd

C:\Users\tensoflow

C:\Users\tensoflow>cd ..

C:\Users>

::: term cmd
@ C:\Users\tensoflow>
cd
| C:\Users\tensoflow
@ C:\Users\tensoflow>
cd ..
@! C:\Users>
:::
属性说明
窗口类型Stringoptional

容器首行的第一个词：sh / powershell / cmd，其中 bash、zsh 按 sh 处理、pwsh 按 powershell 处理；不写就是 sh

自定义标题Stringoptional

类型词后面的文字会作为窗口标题，如 ::: term powershell 部署脚本；不写就用默认标题(Terminal / PowerShell / 命令提示符)

promptStringoptional

每行命令前的提示符，写在头部任意位置，如 ::: term powershell prompt="PS D:\project>"；值含空格必须用引号包裹（单双引号均可），不含空格可裸写 prompt=>；不写就用默认值（sh 为 $、powershell 为 PS C:\Windows\System32>、cmd 为 C:\Users\tensoflow>）

命令行Stringoptional

容器里每一行就是一条命令，逐行渲染、原样显示，>、| 这类字符不会被 markdown 吃掉；空行忽略，一条命令都没有时整个窗口不渲染

// 说明行Stringoptional

以 // 开头的行是它下面那条命令的说明，渲染成命令上方的淡色小字。可以连续写多行说明，复制按钮只复制命令、不带说明

@ 单行提示符Stringoptional

写在命令上方，@ 后跟一个空格再写提示符，如 @ sudo root@server:~#；只作用于紧随其后的那一条命令

@+ 持续提示符Stringoptional

写在命令上方，@+ 后跟一个空格再写提示符，如 @+ root@server:/var/log#；从该行往下一直生效，直到下一个 @/@+ 或容器结束。提示符优先级 @ > @+ > 头部 prompt > 类型默认值；@/@+ 后必须带空格，避免和 @scope/pkg 这类命令冲突

| 输出行Stringoptional

以 | 开头的行是命令输出，如 | C:\Users\tensoflow；顶格显示、不带提示符，原样保留空白和特殊字符。不参与打字动画、不被复制按钮复制

@! 纯提示符行Stringoptional

以 @! 开头的行只有提示符没有命令，如 @! C:\Users>；提示符写在 @! 后，省略则用容器默认提示符，光标常亮表示等待输入。同样不打字、不复制。配合输出行可还原完整终端会话

layoutStringoptionalnested

排布预设：nested 逐层包含 / intersect 两圆相交 / disjoint 互相分离 / venn3 三圆文氏 / free 完全按各项坐标

ratioNumberoptional0.66

仅 nested 有效：相邻两层的直径比（0~1），越小内层缩得越快。三层以上建议 0.6~0.7

opacityNumberoptional

填充不透明度 0~1。不写时包含/互斥为 1（实心），相交/文氏为 0.58（叠加显色）。单项也能在 sets 里单独给

blendBooleanoptional

# 计算机网络组成与功能

## 组成
### 从组成部分看
#### 硬件
 - 主机(内部装有网络适配器即网卡负责发送与接收网络数据)：电脑、手机、物联网设备
 - 通信设备：集线器、交换机、路由器
 - 通信链路：网线、光纤、同轴电缆
#### 软件
 - 方便用户使用、实现资源共享如：Email客户端、聊天软件、网盘软件
#### 协议
 - 规定计算机网络中的通信规则
 - 由硬件、软件共同实现：网络适配器 + 软件 实现网络通信协议
### 从工作方式看
#### 边缘部分
 - 工作方式：直接为用户服务(通信、资源共享)
 - 主要由连接到互联网上的主机及其软件组成
#### 核心部分
 - 工作方式：为边缘部分提供服务(连通性、交换服务)
 - 由大量网络和连接这些网络的路由器组成

### 从逻辑功能看
#### 资源子网
 - 计算机网络中运行应用程序，向用户提供可共享的硬件、软件和信息资源的部分
 - 主要由连接到互联网上的主机组成
#### 通信子网
 - 计算机网络中负责计算机间信息传输的部分。即把计算机和其他用户装置互连在一起的所有通信设备和介质的总称
 - 主要由通信链路 + 通信设备 + 协议构成
 - 注：主机内部实现信息传输的网络适配器、底层协议属于通信子网的范畴

## 功能
### 数据通信
 - 实现计算机之间数据传输。是最基本、最重要的功能
### 资源共享
#### 硬件、软件、数据资源
 - 如：智能音箱 请求服务器处理
 - 如：应用商店
 - 如：分享视频
### 分布式处理
 - 将某个复杂任务分配给网络中多台计算机处理
### 提高可靠性
 - 网络中各台计算机互为替代机
### 负载均衡
 - 网络中各台计算机共同分担繁重工作
### 其他
 - 满足社会需求、生活需求。如：远程办公、远程教育、娱乐等
