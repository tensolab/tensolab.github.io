Git

便捷版Git在文件夹中右键不会出现Git Bash Here。需要手动执行在D:\tensoflow\code\portable\git目录下的add-git-bash.reg脚本。该脚本会将Git加入到注册表，这样就可以在文件夹中右键出现Git Bash Here。

26

开启MySQL

如果新电脑和老电脑存放MySQL的路径不一样则需要修改my.ini文件里的绝对路径。打开MySQL安装根目录中的my.ini文件，把 basedir、datadir 改成新电脑存放路径。

# 管理员CMD进入新电脑安装MySQL的bin目录然后执行下面的命令重新注册系统服务
mysqld --install mysql8

# 启动服务
net start mysql8
